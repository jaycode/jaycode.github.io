Privacy Policy for Mark It Down

Last updated: May 12, 2026

Mark It Down is a Chrome extension that renders Markdown files in the browser and lets you copy rendered selections back as Markdown source.

I built Mark It Down for a small workflow I use often: viewing Markdown output, including ChatGPT-produced Markdown, in a cleaner rendered form while still being able to copy useful parts into my own documents without rebuilding the formatting by hand.

Data collection

Mark It Down does not collect, sell, share, or transmit personal information.

The extension does not use analytics, tracking scripts, advertising identifiers, or remote code. Markdown content is processed locally in your browser.

Local storage

Mark It Down uses Chrome's storage permission only to save local viewer preferences, such as light/dark theme and whether the viewer header is hidden.

These preferences stay in your browser. They are not sent to me or to any third-party service.

Markdown content and clipboard

When you open a Markdown file, Mark It Down renders it locally in the browser.

When you copy a rendered selection, the extension places Markdown text on your clipboard as part of that user-initiated copy action. The extension does not read your clipboard, store copied content, or send copied content anywhere.

Host permissions

Mark It Down runs only on local files and URLs that look like Markdown files, such as .md, .markdown, .mdown, .mkd, and .mkdn files. These permissions are used only to detect and render Markdown pages in Chrome.

Third parties

Mark It Down does not send data to third-party services.

Contact

If you have privacy questions about Mark It Down, please contact me through teguhwijaya.com.
